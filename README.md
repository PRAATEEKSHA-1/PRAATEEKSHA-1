**[Macroeconomic Analysis of HDFC Bank Stock Returns](https://github.com/PRAATEEKSHA-1/Analysis-of-Macroeconomic-Indicators-on-Stock-Market-Returns)**
Applied econometric time-series methods (ADF/KPSS stationarity tests, VAR modeling, Granger causality) to 15+ years of monthly data testing whether inflation, gold, oil, and money supply predict HDFC Bank stock returns. Found only a weak gold-price effect and no significant predictive relationships — a result consistent with the Efficient Market Hypothesis, demonstrating rigorous hypothesis testing over confirmation-seeking.
